=== PREP for U_X (preconditioned 1D Laplacian) ===
q = 20 system qubits (N = 2^20); |J| = ceil(log2(q-1)) = 5; ancillas a, p, J = 7
lambda_j = 2^(j-q+1), j = 0..18; padding weight 2/N = 1.907349e-06; sum = 1.000000000000000
PREP|0>_{pJ} = sqrt(2/N)|1>_p|0>_J + sum_j sqrt(lambda_j)|0>_p|j>_J

construction:
  1. pruned Gray-code state tree on J with marginal weights w(0) = lambda_0 + 2/N,
     w(j) = lambda_j (j >= 1); each level keeps only the higher J bits it depends on
  2. Ry(pi/4) . MCX(J = 0 -> p) . Ry(-pi/4) splits w(0) equally into lambda_0 and 2/N
non-Clifford+T rotations in PREP: 21 (the two Ry(+-pi/4) are exact Clifford+T)
resource circuits replace MCX with an exact dirty-ancilla ladder borrowing system qubits.
idle wires (a and the k register) are hidden.
